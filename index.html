管理页使用点分析

管理页位置/动作 建议接口 说明
打开 FAQ 管理弹窗、切换语言、刷新左侧菜单 GET /faq/getFaqMenu 按 language + proId 查询左侧菜单树；transList.menuName 用于菜单名称，descriptionText 对应描述文案。children 转成组件的 childList。
新增/编辑/删除左侧一级菜单和二级菜单 POST /faq/editFaqMenu 复用左侧菜单编辑表单；parentId=0 为一级菜单，二级菜单带 parentId 和 pageUrl；删除传 isDel=1。二级菜单同时提交 seoTitle、seoKeyword、seoDescription。
点击二级菜单“编辑FAQ内容”、重置内容 GET /faq/getFaqConfigDetailByFaqId 按 faqMenuId + visitorUuid + proId 拉取详情，初始化 FAQ 分类、FAQ 条目、Popular Articles、My Account、Latest Blog Posts；Popular Articles 和 Latest Blog Posts 分别从 faqArticleParentVo、faqBlogParentVo 读取标题和列表。
FAQ 分类新增/编辑/删除 POST /faq/editFaqCate 对应 FAQ 分类卡片；新增后接口若只返回 true，前端会自动刷新详情定位分类 id 后继续保存 FAQ。
FAQ 条目新增/编辑/删除 POST /faq/editFaqItem 对应分类下的 FAQ 卡片；likeCount 在后台只展示，但按接口文档仍随原值提交。
左侧菜单下方推荐列表、拖拽排序、保存推荐顺序 GET /faq/getIsCommendFaq + POST /faq/editFaqItem 按 uid + language + proId 查询 isRecommend=1 的 FAQ；拖拽后重排 sortNum，保存时复用 editFaqItem，并带回 id、categoryId、likeCount、isRecommend、sortNum、title、subTitle、text。
Popular Articles 新增/编辑/删除 POST /faq/editFaqPopularArticle 对应 Popular Articles 列表；sortNo 按前端顺序提交，模块标题通过 parentId + name 保存。
My Account 新增/编辑/删除 POST /faq/editFaqAccount 对应 My Account 用户卡片；详情页按 faqAccountList 读取，保存字段为 imageUrl、jumpLink、imageAlt、title。
Latest Blog Posts 新增/编辑/删除 POST /faq/editFaqLatestBlog 对应 Latest Blog Posts 列表；字段为 imageUrl、jumpLink、imageAlt、title、subTitle，模块标题通过 parentId + name 保存。
FAQ 点赞/取消点赞 POST /faq/addLikeRecord 前台用户行为接口；后台管理页不调用，只展示 likeCount。
当前用户点赞详情 GET /faq/getLoginUserIsLiked 前台用于判断登录用户或游客哪些 FAQ 已点赞；后台管理页暂不需要。

仍需确认的问题

  1. My Account 标题当前只展示默认值，不提供编辑入口；Popular Articles 和 Latest Blog Posts 标题通过各自父对象 name 保存。
  2. getFaqConfigDetailByFaqId 若要回显 My Account，请返回 faqAccountList，字段结构应与 editFaqAccount 一致并包含 transList。
  3. editFaqCate 新增返回 data=true 时，前端已做二次刷新定位；若后端能返回 data.id，可减少一次请求。
  4. 所有 edit 接口删除是否统一传 isDel=1，并且其他字段是否必须完整传入，仍建议后端补充说明。
  5. getIsCommendFaq 的 ShowDoc 示例未展示 sortNum，但联调需求说明推荐列表会返回 sortNum；管理页按真实返回字段排序并保存。
